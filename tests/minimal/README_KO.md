# MOS 6502 Test ROM

[English / 영어](./README.md)

## 소개

MOS 6502 마이크로프로세서 에뮬레이터의 다양한 명령과 주소 지정 모드의 작동을 검증하기 위한 포괄적인 테스트를 제공하는 ROM입니다. 본 테스트 도구는 6502 Assembly로 작성된 소스 코드 (`test.asm`), Python 3으로 작성된 빌드용 스크립트 (`build_test_rom.py`), 마지막으로 자동화된 검증을 위한 도구 (`verify_test.c`)로 구성되어 있습니다.

## ROM 빌드

```bash
python3 build_test_rom.py
```

이후 에뮬레이터에 로드될 수 있는 `test.bin`이 생성됩니다.

## ROM 실행

### 에뮬레이터 동작 (트레이스 활성화)
```bash
./mos6502 -f test.bin -a 8000 -t
```

### 에뮬레이터 동작 (트레이스 비활성화)
```bash
./mos6502 -f test.bin -a 8000
```

### 검증 과정 포함
```bash
clang -std=c99 -O2 verify_test.c cpu.c bus.c memory.c stack.c \
    addressing.c instructions_implementation.c instructions_handlers.c \
    instructions_table.c loader.c trace.c -o verify_test

./verify_test
```

## 테스트 영역

이 ROM은 15가지의 6502 마이크로프로세서의 근본적 동작을 시험하는 테스트로 구성되어 있습니다. 기본적인 로드/저장 연산은 `LDA`/`STA`, `LDX`/`STX`, 그리고 `LDY`/`STY` 명령이 테스트되고, 산술 연산의 경우 `ADC`와 `SBC`, 마지막으로 논리 연산의 경우 `AND`, `ORA`, 그리고 `EOR` 명령이 테스트됩니다.

레지스터 명령의 경우 `INX`와 `DEY`를, 실행 흐름의 경우 `BEQ`, `JSR`/`RTS`, 그리고 `PHA`/`PLA`를, 주소 지정 모드의 경우 `(ABS,X)`와 `(ZP,X)`이 테스트됩니다. 

## 메모리 맵

```
$0200-$020E  테스트 결과
$8000-$8073  테스트 코드
$8074-$807D  곱연산 서브루틴
$807E-$8082  DATA 배열
```

## 예상 결과

실행 이후, 메모리의 배열은 다음과 같아야 합니다.

| 주소 | 값 | 테스트 설명 |
|---------|-------|------------------|
| $0200 | $42 | LDA #$42, STA $0200 |
| $0201 | $10 | LDX #$10, STX $0201 |
| $0202 | $20 | LDY #$20, STY $0202 |
| $0203 | $15 | ADC: $10 + $05 |
| $0204 | $12 | SBC: $15 - $03 |
| $0205 | $03 | AND: $0F & $03 |
| $0206 | $07 | ORA: $05 \| $02 |
| $0207 | $F0 | EOR: $FF ^ $0F |
| $0208 | $03 | INX 3회 실행 |
| $0209 | $03 | DEY를 $05로부터 2회 실행 |
| $020A | $AA | 테스트 결과의 분기 |
| $020B | $06 | 2+2+2를 실행하는 서브루틴 |
| $020C | $55 | 스택 테스트 (PHA/PLA) |
| $020D | $44 | 인덱스된 주소 연산: DATA[3] |
| $020E | $99 | 제로 페이지 인덱싱 |

## 테스트 상세

산술 연산 테스트의 경우 Carry Flag의 관리를 포함하여 `ADC`와 `SBC`를 검증하고, 논리 연산의 경우 비트와이즈 `AND`, `OR`, 그리고 `XOR`의 기능을 검증합니다. 제어 흐름 증명은 `BEQ`를 통한 조건 분기와 `JSR`/`RTS`를 사용한 조건 분기가 포함됩니다.

본 테스트 도구는 즉시 (`LDA #$42`), 절대 (`STA $0200`), 제로 페이지 (`STA $10`), 절대 인덱싱 (`LDA $807E,X`), 그리고 제로 페이지 인덱싱 (`LDA $10,X`)과 같은 여러 주소 지정 모드를 테스트하고, 레지스터 연산의 경우 누산기와 인덱스 레지스터 (`TAX`, `TAY`, `TXA`), 증감 연산자 (`INX`, `INY`, `DEX`, `DEY`), 그리고 스택 조작 (`PHA`, `PLA`) 명령을 테스트합니다.

## 검증

본 검증 프로그램은 15개 테스트 전 과정을 구동하고, 예측값과 대조하여 PASS 또는 FAIL을 출력합니다. 정상적으로 작동하는 에뮬레이터의 경우, 전 테스트 과정이 통과되는 것이 예상됩니다.
